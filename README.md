# pes6-xbox-recomp

[EN] In order to play the game, you have to provide your own game files, it can be through the game folder, an ISO of the game or the default.xex in the main folder of the game files. The only compatible version is the PAL version of PES 6
Once install the game through the launcher, you can configure internal resolution in the pes6.toml file, you have to change the resolution_scale parameter, setting it to 1 makes it run on 720p (Native), setting it to 2 makes it run around 1080p and setting it to 3 makes it run around 4K

[ES] Para jugar al juego, deben proveer sus propios archivos del juego, ya sea mediante la carpeta del juego, un ISO del juego o el archivo default.xex en la carpeta principal del juego. La única versión compatibles es la versión PAL de PES 6
Una vez instalado el juego mediante el launcher, puedes configurar la resolución interna mediante el archivo pes6.toml, debes cambiar el parametro resolution_scale, al colocarlo en 1 el juego correrá en 720p (Nativo), al colocarlo en 2 el juego correrá aproximadamente en 1080p y al colocarlo en 3 el juego correrá aproximadamente en 4K
