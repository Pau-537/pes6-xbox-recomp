# pes6-xbox-recomp

[EN] In order to play the game, you have to provide your own game files, it can be through the game folder, an ISO of the game or the default.xex in the main folder of the game files. The only compatible version is the PAL version of PES 6

[ES] Para jugar al juego, deben proveer sus propios archivos del juego, ya sea mediante la carpeta del juego, un ISO del juego o el archivo default.xex en la carpeta principal del juego. La única versión compatibles es la versión PAL de PES 6
